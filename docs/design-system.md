## Design System Prompt — Seer Varisai Thattu

Create a complete, premium design system for a family-run **Seer Varisai Thattu and traditional ceremonial gift arrangement business**.

The design system should combine **South Indian traditional aesthetics with modern luxury, elegance, and contemporary web design**.

The goal is to create a consistent visual language that can be used across the entire website, including the homepage, collection pages, product pages, gallery, enquiry forms, about page, and future admin/customer interfaces.

### 1. Brand Personality

The design system should communicate:

* Traditional
* Elegant
* Premium
* Warm
* Authentic
* Family-oriented
* Trustworthy
* Festive
* Sophisticated

The design should feel like a **premium traditional Indian wedding brand**, not a generic e-commerce store or SaaS application.

### 2. Color System

Create a carefully balanced color palette based on:

* Warm ivory / cream as the primary background
* Deep maroon / burgundy as a primary brand color
* Muted antique gold as an accent
* Warm brown / charcoal for primary text
* Soft beige / sand for secondary backgrounds
* White for cards and surfaces

Define semantic color tokens such as:

* Background
* Foreground
* Primary
* Primary foreground
* Secondary
* Secondary foreground
* Accent
* Muted
* Border
* Card
* Success
* Warning
* Error

Avoid extremely bright gold, neon colors, excessive gradients, or overly saturated colors.

The palette should remain elegant and accessible.

### 3. Typography

Create a typography system using a combination of:

* An elegant serif typeface for major headings and brand storytelling
* A clean modern sans-serif typeface for body text, navigation, buttons, forms, and UI elements

Define:

* Display
* H1
* H2
* H3
* H4
* Body large
* Body
* Body small
* Caption
* Button
* Navigation

The typography should create a strong contrast between **traditional elegance and modern usability**.

### 4. Spacing System

Create a consistent spacing scale that can be reused throughout the website.

Use a structured spacing system rather than arbitrary margins.

Define tokens for:

* 4px
* 8px
* 12px
* 16px
* 24px
* 32px
* 48px
* 64px
* 80px
* 96px
* 128px

Use larger spacing values for premium editorial sections and smaller spacing values for dense UI components.

### 5. Layout System

Create a responsive layout system with:

* Mobile
* Tablet
* Desktop
* Large desktop

Define:

* Maximum content width
* Page gutters
* Section spacing
* Grid systems
* Column layouts
* Responsive breakpoints

The layout should prioritize generous whitespace and strong visual hierarchy.

### 6. Buttons

Create a complete button system including:

* Primary button
* Secondary button
* Outline button
* Ghost button
* Text button
* Icon button
* WhatsApp/contact CTA

Define states for:

* Default
* Hover
* Active
* Focus
* Disabled
* Loading

Buttons should feel elegant and premium, with subtle transitions rather than exaggerated effects.

### 7. Cards

Create reusable card patterns for:

* Collection cards
* Product cards
* Occasion cards
* Testimonial cards
* Gallery cards
* Service cards

Cards should use subtle borders, shadows, rounded corners where appropriate, and high-quality imagery.

Avoid excessive rounded cards that make the website look like a generic SaaS dashboard.

### 8. Image System

Photography is a major part of the brand.

Define image treatments for:

* Hero images
* Product images
* Gallery images
* Collection images
* Editorial images

Use elegant aspect ratios and consistent image cropping.

Images should feel editorial and premium.

Include subtle image hover interactions such as:

* Slow zoom
* Overlay reveal
* Caption reveal

### 9. Forms

Create reusable form components for the customer enquiry flow.

Include:

* Text input
* Phone input
* Select
* Date picker
* Number selector
* Textarea
* Checkbox
* Radio buttons
* Budget selector
* Occasion selector

Form states should include:

* Default
* Focus
* Filled
* Error
* Disabled
* Success

Forms should feel simple and trustworthy because they are part of the customer conversion journey.

### 10. Navigation

Create a responsive navigation system.

Desktop navigation should include:

* Logo
* Home
* Collections
* Occasions
* Gallery
* About
* Contact
* Primary enquiry CTA

Mobile navigation should use a clean animated menu.

The navigation should remain minimal and elegant.

### 11. Decorative Elements

Introduce subtle visual elements inspired by South Indian traditional aesthetics.

Possible elements include:

* Minimal floral motifs
* Subtle kolam-inspired patterns
* Thin ornamental borders
* Elegant gold dividers
* Decorative section headings
* Traditional-inspired icons

These elements should be subtle and modern.

Do not make the website look overly decorative or old-fashioned.

### 12. Animation System

Create a consistent motion language.

Animations should be:

* Smooth
* Slow and elegant
* Purposeful
* Subtle
* Consistent

Define reusable animation patterns for:

* Fade in
* Slide up
* Image reveal
* Text reveal
* Hover
* Page transition
* Modal
* Menu opening
* Scroll reveal
* Parallax

Use animation durations and easing curves consistently.

Avoid excessive bouncing, spinning, or flashy animations.

Respect `prefers-reduced-motion`.

### 13. Icons

Use a consistent icon library and icon style.

Icons should be:

* Minimal
* Elegant
* Consistent
* Easy to understand

Avoid mixing multiple icon styles.

### 14. Responsive Design

Every component should be designed mobile-first.

Ensure that:

* Typography scales correctly
* Images maintain their visual impact
* Navigation remains usable
* Buttons remain accessible
* Forms are easy to complete
* Animations remain performant
* Content does not become overcrowded

### 15. Accessibility

The design system must follow good accessibility practices.

Include:

* Sufficient color contrast
* Visible focus states
* Keyboard navigation
* Accessible form labels
* Proper button states
* Reduced-motion support
* Appropriate touch target sizes
* Semantic UI structure

### 16. Component Architecture

Create reusable components rather than designing each page independently.

The design system should provide reusable primitives such as:

`Button`

`Container`

`Section`

`Heading`

`Badge`

`Card`

`Image`

`Input`

`Select`

`Textarea`

`Modal`

`Navbar`

`Footer`

`Gallery`

`ProductCard`

`CollectionCard`

`TestimonialCard`

`EnquiryForm`

### 17. Design Tokens

Define the design system using reusable tokens for:

* Colors
* Typography
* Font sizes
* Font weights
* Line heights
* Letter spacing
* Spacing
* Border radius
* Shadows
* Breakpoints
* Animation durations
* Animation easing

The final design system should be structured so that changing a brand color, font, spacing value, or animation style can be done centrally rather than modifying individual components.

### Final Design Direction

The final visual language should feel like:

**Traditional Tamil culture + Luxury wedding brand + Modern editorial website + Premium digital experience**

It should look beautiful even without animations, and the animations should enhance the experience rather than compensate for weak design.

Prioritize **consistency, elegance, usability, performance, accessibility, and brand identity** across every component.
