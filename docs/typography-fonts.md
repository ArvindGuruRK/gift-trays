# Typography System — Seer Varisai Thattu

Create a premium typography system for a family-run **Seer Varisai Thattu and traditional ceremonial gift arrangement brand**.

The typography should combine **traditional South Indian elegance with modern luxury and excellent digital readability**.

Use a two-font typography system:

## 1. Display / Heading Font

**Font:** Cormorant Garamond

Use Cormorant Garamond for:

* Hero headlines
* H1
* H2
* H3
* H4
* Collection names
* Product names
* Large editorial statements
* Brand storytelling
* Decorative headings

Recommended weights:

* 400 — Elegant/light editorial text
* 500 — Primary headings
* 600 — Strong headings
* 700 — Use sparingly for emphasis

The typography should feel elegant, refined, timeless, and luxurious.

Avoid excessive use of bold weights.

---

## 2. Body / UI Font

**Font:** Manrope

Use Manrope for:

* Body text
* Paragraphs
* Navigation
* Buttons
* Forms
* Product descriptions
* Prices
* Labels
* Metadata
* Captions
* Secondary information
* All functional UI elements

Recommended weights:

* 400 — Regular body text
* 500 — Medium emphasis
* 600 — Buttons and important UI
* 700 — Strong emphasis when required

Manrope should provide a clean, modern, highly readable contrast to the elegant serif typography.

---

# Line Height

Use generous line heights for readability.

### Headings

Approximately:

`0.95–1.1`

### Body

Approximately:

`1.5–1.7`

### UI

Approximately:

`1.3–1.5`

Large editorial headings should have tighter line spacing, while paragraphs should have comfortable spacing.

---

# Letter Spacing

Use subtle letter spacing.

### Headings

Slightly tight:

`-0.02em to -0.04em`

### Body

Approximately:

`0`

### Uppercase UI Labels

Use:

`0.08em – 0.12em`

This can be used for small labels such as:

`OUR COLLECTION`

`EXPLORE`

`CONTACT US`

Avoid excessive letter spacing in normal text.

---

# Typography Rules

1. Use **Cormorant Garamond for emotion, storytelling, and visual identity**.

2. Use **Manrope for usability, navigation, information, and functional UI**.

3. Never use Cormorant Garamond for long paragraphs.

4. Never use multiple unrelated font families.

5. Maintain strong hierarchy between headings and body content.

6. Use responsive typography across mobile, tablet, and desktop.

7. Avoid excessive font weights.

8. Maintain sufficient contrast and readability.

9. Keep typography elegant and spacious.

10. The typography should look premium even without decorative elements or animations.

---

# Brand Typography Philosophy

The final typography should communicate:

**Traditional Tamil Elegance**

*

**Luxury Wedding Aesthetic**

*

**Modern Editorial Design**

*

**Clean Digital Experience**

The overall typography should feel like a **premium Indian wedding boutique**, not a generic e-commerce store, SaaS application, or overly decorative traditional website.

## Final Font Pairing

**Cormorant Garamond**
→ Brand identity, headings, storytelling

**Manrope**
→ Body, UI, navigation, forms, buttons

This font pairing should become the **official typography foundation of the entire Seer Varisai Thattu design system**.
